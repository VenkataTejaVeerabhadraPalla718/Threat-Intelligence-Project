# SENTINEL-X — Cyber Threat Intelligence Platform

## Overview
SENTINEL-X is an AI-assisted Cyber Threat Intelligence platform built around MongoDB and a modular application architecture.

## Main Technologies
- MongoDB replica sets
- FastAPI
- Python
- Docker and Docker Compose
- Ollama and local LLM integration
- Retrieval-Augmented Generation (RAG)
- HTML, CSS and JavaScript

## Main Components
- Backend API and authentication
- Threat intelligence management
- AI assistant integration
- Frontend dashboard
- Docker deployment configuration
- Supporting scripts and documentation

## Local Setup
1. Install Docker Desktop.
2. Install Python if required by the selected services.
3. Configure your local environment using the provided environment example.
4. Start the required services using Docker Compose.
5. Open the application at the configured local address.

## Security
Never commit `.env` files, API tokens, passwords, private keys, database backups or production credentials.
